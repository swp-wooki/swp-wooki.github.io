Real Analysis 9: Good Kernels and Approximation

Created on June 03, 2026

2026   ·   real-analysis   measure-theory   lecture-notes   ·   real-analysis

이 글은 2026년 봄학기 실변수함수론(MAT4033) 강의노트를 주제별로 정리한 글입니다.

Definition. A family \(\{K_\delta\}_{\delta > 0} \subset L^1(\mathbb{R}^d)\) is an approximation to the identity if

  1. \(\int_{\mathbb{R}^d} K_\delta = 1 \quad \forall \delta > 0\),

  2. \(\vert K_\delta(x)\vert \le A \delta \min \left\{ \frac{1}{\delta^{d+1}}, \frac{1}{\vert x\vert ^{d+1}} \right\}\) for all \(\delta > 0\) and for all \(x \in \mathbb{R}^d\).

Example.

  1. Let \(\varphi \ge 0\) be bounded, supported on \(\overline{B}_1\), and such that \(\int \varphi = 1\). Then,

    \[K_\delta(x) := \frac{1}{\delta^d} \varphi\left(\frac{x}{\delta}\right)\]

    is an approximation to the identity.

  2. The Poisson kernel, heat kernel, Fej'{e}r kernel, \dots See the textbook!

Before we seek to following theorem, recall that we have defined the convolution \(f * K_\delta\) by

\[(f * g)(x) \coloneq \int_{\mathbb{R}^d} f(x-y)g(y)dy\]

Theorem 2.1.

If \(f \in L^1(\mathbb{R}^d)\), then

\[(f * K_\delta)(x) \to f(x) \quad \text{as } \delta \to 0\]

for every Lebesgue point \(x\). In particular, the limit holds a.e. <div class="real-analysis-footnote" markdown="1">Note: Note that \(\int_{\mathbb{R}^d} f(x-y)K_\delta(y)dy - \int_{\mathbb{R}^d} f(x)K_\delta(y)dy = (f * K_\delta)(x) - f(x)\)</div>

To prove Theorem 2.1, we need the following lemma.

Lemma 2.2.

Let \(f \in L_{loc}^1\) and let \(x\) be a Lebesgue point of \(f\). Then,

\[r \mapsto A(r) := \frac{1}{r^d} \int_{\vert y\vert \le r} \vert f(x-y) - f(x)\vert dy\]

is continuous, bounded, and \(\lim_{r \to 0} A(r) = 0\).

Proof. Note that continuity of \(A\) follows from proposition 1.12 in Chapter 2, and \(\lim_{r \to 0} A(r) = 0\) follows from the definition of Lebesgue point. It remains to show that \(A\) is bounded on \((1, \infty)\). That is,

\[\text{ETS : } A \text{ is bounded on } (1, \infty).\]

If \(r > 1\), then

\[\begin{aligned} A(r) &\le \frac{1}{r^d} \int_{\vert y\vert \le r} \vert f(x-y)\vert dy + \vert B_1\vert \vert f(x)\vert \\ &\le \vert \vert f\vert \vert _{L^1} + \vert B_1\vert \vert f(x)\vert < \infty \end{aligned}\]

Note: Calculation of \(\frac{1}{r^d} \int_{\vert y\vert \le r} \vert f(x)\vert dy\) is given by \(\frac{1}{r^d} \int_{\vert y\vert \le r} \vert f(x)\vert dy = \frac{1}{r^d} \vert B_r\vert \vert f(x)\vert = \vert B_1\vert \vert f(x)\vert\)</div>

Proof of Theorem 2.1.

We write

\[\begin{aligned} \vert (f * K_\delta)(x) - f(x)\vert &\le \int \vert f(x-y) - f(x)\vert \vert K_\delta(y)\vert dy \\ &\le \int_{\vert y\vert \le \delta} \vert f(x-y) - f(x)\vert \frac{c}{\delta^d} dy \\ &+ \sum_{k=0}^{\infty} \int_{2^k \delta < \vert y\vert \le 2^{k+1}\delta} \vert f(x-y) - f(x)\vert \frac{c\delta}{(2^k \delta)^{d+1}} dy \\ &\lesssim A(\delta) + \sum_{k=0}^{\infty} \frac{1}{2^k} A(2^{k+1}\delta) \qquad (\ast) \end{aligned}\]

Note: If \(k=0 : \delta < \vert y\vert \le 2\delta, \quad k=1 : 2\delta < \vert y\vert \le 4\delta\)</div>

Let \(\epsilon > 0\). Then there exists \(N \in \mathbb{N}\) such that

\[\sum_{k=N}^{\infty} 2^{-k} < \epsilon\]

By Lemma 2.2, there exists \(\delta > 0\) such that

\[A(2^k \delta) < \frac{\epsilon}{N} \quad \text{for } k = 0, 1, \dots, N-1.\]

Recalling that \(A\) is bounded, we have

\[(\ast) \le \frac{\epsilon}{N} + \frac{\epsilon}{N} \sum_{k=0}^{N-1} \frac{1}{2^k} + C \epsilon \lesssim \epsilon\]

Theorem 2.3.

If \(f \in L^1\), then \(f * K_\delta \in L^1\) and

\[\vert \vert f * K_\delta - f\vert \vert _{L^1} \to 0 \quad \text{as } \delta \to 0.\]

Proof. Homework.
