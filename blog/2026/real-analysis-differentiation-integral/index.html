Real Analysis 8: Lebesgue Differentiation and the Hardy–Littlewood Maximal Function

이 글은 2026년 봄학기 실변수함수론(MAT4033) 강의노트를 주제별로 정리한 글입니다.

Observation for Main Question 1.

From the definition of differentiation, we can observe: \begin{align} \text{Main Question 1} \iff F’(x) &:= \lim_{h \to 0} \frac{F(x+h) - F(x)}{h} \ &= \lim_{h \to 0} \frac{1}{h} \int_x^{x+h} f(y) dy \ &= \lim_{\overset{|I| \to 0}{x \in I}} \frac{1}{|I|} \int_I f(y) dy \ &\overset{?}{=} f \end{align} where $I = (x, x+h)$ for some $h > 0$ and $|I|$ denotes the length of $I$. Therefore, the main question 1 is equivalent to whether the last equality [ \lim_{|I| \to 0} \frac{1}{|I|} \int_I f(y) dy = f ] holds (at least a.e.) for $f$. Note that this expression [ \frac{1}{|I|} \int_I f(y) dy ] is the average value of $f$ over $I$, and we expect that its limit tend to $f(x)$ as $|I| \to 0$.

Now let us extend this observation to higher dimension. For $f \in L^1(\mathbb{R}^d)$, [ \lim_{\overset{m(B) \to 0}{x \in B}} \frac{1}{m(B)} \int_B f(y) dy \; \overset{?}{=} \; f(x) \quad \text{a.e. } x ] where $B \subset \mathbb{R}^d$ is a ball with radius $r$. Above question is so called averaging problem. Furthermore, we may define average integral of $f$ over $B$ as [ \mathop{\rlap{-}\int}_{B} f(y)dy \coloneq \frac{1}{m(B)} \int_B f(y) dy ] Hence, we can rewrite the above question as follows:

Main Question 1(Revised).

If $f \in L^1(\mathbb{R}^d)$, is it true that
\[
\lim_{\overset{m(B) \to 0}{x \in B}} \frac{1}{m(B)} \int_B f(y) dy \; \overset{?}{=} \; f(x) \quad \text{a.e. } x
\]
that is, the average value of $f$ over a ball would tend to $f(x)$ as $m(B) \to 0$. Equivalently,
\[
\text{Is that true for } \quad \mathop{\rlap{-}\int}_{B} f(y) dy \to f(x) \quad \text{a.e. } x \: ?
\]

Remark.

If $f$ is continuous at $x$, then for all $\epsilon > 0$, [ \exists : \delta > 0 \text{ s.t. } |f(x) - f(y)| < \epsilon \text{ whenever } |x - y| < \delta. ] Note that \begin{align} \mathop{\rlap{-}\int}_{B} f(x) dy &= \frac{1}{m(B)} \int_B f(x) dy \ &= \frac{1}{m(B)} f(x) \int_B dy \ &= \frac{1}{m(B)} f(x) m(B) = f(x). \end{align} Now we claim that if f is continuous, then $\lim_{m(B) \to 0} \mathop{\rlap{-}\int}_B f(y) dy = f(x)$. That is, [ \mathop{\rlap{-}\int}_B f(y) dy \to f(x) \; \text { a.e. } x \quad \text{as } m(B) \to 0. ] Indeed, \begin{align} \left| f(x) - \mathop{\rlap{-}\int}_B f(y) dy \right| &= \left| \mathop{\rlap{-}\int}_B f(x)dy - \mathop{\rlap{-}\int}_B f(y)dy \right| \ &\le \mathop{\rlap{-}\int}_B |f(x) - f(y)| dy < \epsilon \end{align} whenever $x \in B \subset B(x, \delta)$. Take $m(B) \to 0$, we get the desired result.

Hardy-Littlewood maximal function

Hardy-Littlewood maximal function.

For $f \in L^1(\mathbb{R}^d)$, its maximal function \(f^* : \mathbb{R}^d \to \overline{\mathbb{R}}\) is defined by [ f^*(x) = \sup_{x \in B} \mathop{\rlap{-}\int}_B |f(y)| dy ] where the supremum is taken over all balls $B$ containing $x$.

The main properties of the maximal function are summarized in the following theorem.

Theorem 1.1.

Let $f \in L^1(\mathbb{R}^d)$. Then

  1. $f^*$ is measurable

  2. $f^* < \infty$ for a.e. $x$

  3. $f^$ satisfies [ m({x \in \mathbb{R}^d : f^(x) > \alpha}) \le \frac{3^d}{\alpha} ||f||_{L^1(\mathbb{R}^d)} \quad \forall \; \alpha > 0 ]

Remark.

  1. (Tchebychev inequality) In the previous chapter, we have proved that [ \text{for all } g \in L^1(\mathbb{R}^d) \text{ and } \alpha > 0, \quad m({ |g| > \alpha }) \le \frac{1}{\alpha} ||g||_{L^1(\mathbb{R}^d)} \quad \text{(weak-type)} ]

  2. We will see in Theorem 1.3 that [ f^{*}(x) \ge |f(x)| \quad \text{for a.e. } x. ]

  3. Nevertheless $f^* \notin L^1$ in general. (See Exercise 4 \& 5).

To prove Theorem 1.1, we need the following lemma.

Lemma 1.2 (Vitali covering lemma).

Let $\mathcal{B} = {B_l}{l=1}^N$ be a collection of open balls with $B_l = B(x_l, r_l)$ in $\mathbb{R}^d$. Then there exists a disjoint subcollection ${B{i_1}, \dots, B_{i_k}}$ of $\mathcal{B}$ s.t. [ m\left( \bigcup_{l=1}^N B_l \right) \le 3^d \sum_{j=1}^k m(B_{i_j}) ]

Proof.

  1. We pick a ball with maximal radius $B_{i_{1}}$. Then we delete all balls in $\mathcal{B}$ such that intersecting with $B_{i_1}$, including $B_{i_1}$ itself. Now denote $\tilde{B}{i_1}$ such that [ \tilde{B}{i_{1}} = B(x_1, 3r_{i_1}). ] Thus, every deleted balls are contained in $\tilde{B}_{i_1}$.

  2. Since $\mathcal{B}$ is finite, after at most $N$ steps, we find a collection of disjoint balls [ B_{i_1}, \dots, B_{i_k} ] Let $\tilde{B}{i_j} = B(x{j}, 3r_{i_j})$ for $j = 1, \dots, k$. Then, for each $B \in \mathcal{B}$, there exists $B_{i_j}$ such that [ B \cap B_{i_j} \neq \emptyset \implies B \subset \tilde{B}_{i_j}. ]

  3. Therefore, [ \bigcup_{l=1}^N B_l \subset \bigcup_{j=1}^k \tilde{B}{i_j} \implies m\left( \bigcup{l=1}^N B_l \right) \le m\left( \bigcup_{j=1}^k \tilde{B}{i_j} \right) \le 3^d \sum{j=1}^k m(B_{i_j}) ]

Proof of Theorem 1.1.

  1. Observe that $E_\alpha = {x : f^(x) > \alpha}$ is open. Indeed, if $\overline{x} \in E_\alpha$, then [ f^(\overline{x}) = \sup_{\overline{x} \in B} \mathop{\rlap{-}\int}B |f(y)| dy > \alpha ] holds, we can pick such a ball $B \subset E\alpha$ so that [ \overline{x} \in B \quad \text{ and } \quad \mathop{\rlap{-}\int}B |f(y)| dy > \alpha ] so any point $x$ close enough to $\overline{x}$ also belongs to $B$. Hence, $E\alpha$ is open.

  2. This follows from (iii) : Indeed, since [ {f^* = \infty} \subset {f^* > \alpha} ] we have [ m({f^* = \infty}) \le m({f^* > \alpha}) \le \frac{3^d}{\alpha} ||f||_{L^1}. ] Letting $\alpha \to \infty$ shows that $m({f^* = \infty}) = 0$.

  3. For each $x \in E_\alpha = {f^* > \alpha}$, there exists a ball $B_x \ni x$ such that [ \mathop{\rlap{-}\int}{B_x} |f| > \alpha, \quad \text{i.e. } m(B_x) < \frac{1}{\alpha} \int{B_x} |f|. ] Fix any compact $K \subset E_\alpha$. Since [ K \subset \bigcup_{x \in E_\alpha} B_x ] there exists a finite subcover of $\cup B_x$, say [ K \subset \bigcup_{l=1}^N B_l ] By the VCL, there exists a subcollection $B_{i_1}, \dots, B_{i_k}$ of disjoint balls such that [ m\left(\bigcup_{l=1}^N B_l\right) \le 3^d \sum_{j=1}^k m(B_{i_j}). ] Therefore, \begin{align} m(K) &\le m\left(\bigcup_{l=1}^N B_l\right) \ &\le 3^d \sum_{j=1}^k m(B_{i_j}) \ &\le \frac{3^d}{\alpha} \sum_{j=1}^k \int_{B_{i_j}} |f| = \frac{3^d}{\alpha} \int_{\bigcup_{j=1}^k B_{i_j}} |f| \le \frac{3^d}{\alpha} \int_{\mathbb{R}^d} |f| \end{align} for any compact $K \subset E_\alpha$.

Theorem 1.3 (Lebesgue differentiation theorem).

If $f \in L^1(\mathbb{R}^d)$, then [ \lim_{\overset{m(B) \to 0}{x \in B}} \mathop{\rlap{-}\int}_B f(y) dy = f(x) \quad \text{for a.e. } x. ]

Proof. ETS : $m(E_\alpha) = 0$ for all $\alpha > 0$Note: Since if $m(E_\alpha) = 0 \; \forall \alpha > 0 \implies m(E) = 0$ where $E = \bigcup_{n=1}^\infty E_{\frac{1}{n}}$. Then, [ x \notin E \iff x \in E^c = \left(\bigcup_{n=1}^\infty E_{\frac{1}{n}}\right)^c = \bigcap_{n=1}^\infty E_{\frac{1}{n}}^c ] this implies that $x \in E_{\frac{1}{n}}^c$ for all $n \in \mathbb{N}$, where [ E_{\frac{1}{n}}^c = \left{x : \limsup_{\overset{m(B) \to 0}{x \in B}} \left| \mathop{\rlap{-}\int}B f(y) dy - f(x) \right| \le \frac{2}{n} \right} ] therefore, if $x \notin E$, then desired limit holds. Since $m(E) = 0$, we conclude that the limit holds for a.e. $x$.</span>, where [ E\alpha := \left{x : \underbrace{\limsup_{\overset{m(B) \to 0}{x \in B}} \left| \mathop{\rlap{-}\int}B f(y) dy - f(x) \right|}{(\ast)} > 2\alpha \right} ] Fix $\alpha > 0$ and let $\epsilon > 0$. Then [ \exists \; g \in C_c^0(\mathbb{R}^d) \text{ such that } ||f - g||{L^1} < \epsilon \tag{$\ast$} ] Note: Theorem 2.4 in chapter 2 states that $C_c^0(\mathbb{R}^d)$ is dense in $L^1(\mathbb{R}^d)$. Recall that the definition of density on $L^1$ space is as follows: $\mathcal{F}$ is dense in $L^1$ if for all $f \in L^1$ and $\epsilon > 0$, there exists $g \in \mathcal{F}$ such that $||f - g||_{L^1} < \epsilon$. In previous remark, we know that for such continuous function $g$, the following holds: [ \lim{\overset{m(B) \to 0}{x \in B}} \mathop{\rlap{-}\int}B g(y) dy = g(x). ] Thus bu using simple triangle inequality, we find \begin{align*} (\ast) = &\limsup{\overset{m(B) \to 0}{x \in B}} \left| \mathop{\rlap{-}\int}B (f(y) - g(y)) dy + \mathop{\rlap{-}\int}_B g(y) dy - g(x) + g(x) - f(x) \right| \ &\le \limsup{\overset{m(B) \to 0}{x \in B}} \left| \mathop{\rlap{-}\int}B (f(y) - g(y)) dy \right| + \limsup{\overset{m(B) \to 0}{x \in B}} \left| \mathop{\rlap{-}\int}B g(y) dy - g(x) \right| + |g(x) - f(x)| \ &\le (f - g)^*(x) + |f(x) - g(x)| \end{align*} since [ \limsup{\overset{m(B) \to 0}{x \in B}} \left| \mathop{\rlap{-}\int}B (f(y) - g(y)) dy \right| \le (f - g)^*(x) \quad \text{and} \quad \limsup{\overset{m(B) \to 0}{x \in B}} \left| \mathop{\rlap{-}\int}_B g(y) dy - g(x) \right| = 0, ] where the first inequality follows from the definition of maximal function, and the second equality follows from the continuity of $g$. Note that [ 2\alpha < (\ast) \le (f - g)^(x) + |f(x) - g(x)| \implies 2\alpha < (f - g)^(x) + |f(x) - g(x)| ] since both are positive, at least one of them is greater than $\alpha$. Note: If $a, b > 0$ and $a + b > 2\alpha$, then either $a > \alpha$ or $b > \alpha$. If not, then $a \le \alpha$ and $b \le \alpha$, thus $a + b \le 2\alpha$, which is a contradiction.

Let [ F_\alpha = {x : (f - g)^*(x) > \alpha} \quad \text{and} \quad G_\alpha = {x : |f(x) - g(x)| > \alpha}. ] Then, using the above observation, we find [ x \in F_\alpha \text{ or } x \in G_\alpha \implies E_\alpha \subset F_\alpha \cup G_\alpha ] therfore, [ E_\alpha \subset F_\alpha \cup G_\alpha \implies m(E_\alpha) \le m(F_\alpha) + m(G_\alpha). ] By Tchebyshev’s inequality, we have [ m(G_\alpha) \le \frac{1}{\alpha} ||f - g||{L^1} < \frac{1}{\alpha} \epsilon ] and by the weak type estimate for the maximal function, we have [ m(F\alpha) \le \frac{A}{\alpha} ||f - g||{L^1} < \frac{A}{\alpha} \epsilon ] Thus, [ m(E\alpha) < \frac{1 + A}{\alpha} \epsilon ] since $\epsilon$ was arbitrary, we conclude that $m(E_\alpha) = 0$.

Remark.

  1. Theorem 1.3 (which applied to $|f|$) implies that [ f^(x) \ge |f(x)| \quad \text{for a.e. } x. ] indeed, [ \lim_{\overset{m(B) \to 0}{x \in B}} \mathop{\rlap{-}\int}_B |f(y)| dy = |f(x)| \quad \text{for a.e. } x. ] then [ f^(x) = \sup_{x \in B} \mathop{\rlap{-}\int}B |f(y)| dy \ge \lim{\overset{m(B) \to 0}{x \in B}} \mathop{\rlap{-}\int}_B |f(y)| dy = |f(x)| \quad \text{for a.e. } x. ]

Definition. We say that $f$ is locally integrable if for every ball $B$ the function $f(x)\chi_B(x)$ is integrable. We denote the set of locally integrable functions by \(L_{loc}^1(\mathbb{R}^d) = \{f : f \in L^1(K) \text{ for any compact } K \subset \mathbb{R}^d\}.\)

Theorem 1.4.

Theorem 1.3 is a local property: it holds for
    \[
    f \in L_{loc}^1(\mathbb{R}^d) \supset L^1(\mathbb{R}^d)
    \]

Definition. Let $E \in \mathcal{M}$. We say that $x \in \mathbb{R}^d$ is a point of (Lebesgue) density of $E$ if [ \lim_{\overset{m(B) \to 0}{x \in B}} \frac{m(B \cap E)}{m(B)} = 1. ]

This definition of a point of density says that small balls around x are almost entirely covered by $E$. More precisely, for every $\alpha < 1$ close to 1, and every ball of sufficiently small radius containing $x$, we have

[ m(B \cap E) > \alpha m(B). ]

Corollary 1.5.

Let $E \in \mathcal{M}$. Then

  1. Almost every point $x \in E$ is a point of density of $E$.

  2. Almost every point $x \notin E$ is not a point of density of $E$.

Proof. Put $f = \chi_E$. Then, \begin{align} \lim_{\overset{m(B) \to 0}{x \in B}} \frac{1}{m(B)} \int_B \chi_E(y) dy &= \lim_{\overset{m(B) \to 0}{x \in B}} \frac{1}{m(B)} \left( \int_{B \cap E} \chi_{E}dy + \int_{B \setminus E} \chi_{E}dy \right) \ &= \lim_{\overset{m(B) \to 0}{x \in B}} \frac{1}{m(B)} \left( \int_{B \cap E} 1 dy + \int_{B \setminus E} 0 dy \right) \ &= \lim_{\overset{m(B) \to 0}{x \in B}} \frac{m(B \cap E)}{m(B)} = \chi_E(x) \quad \text{for a.e. } x. \end{align} Therefore, [ \chi_E(x) = \lim_{\overset{m(B) \to 0}{x \in B}} \frac{m(B \cap E)}{m(B)} = \begin{cases} 1 & \text{if } x \in E \ 0 & \text{if } x \notin E \end{cases} ]

Definition. Let $f \in L_{loc}^1(\mathbb{R}^d)$. We say that $\overline{x} \in \mathbb{R}^d$ is the Lebesgue point of $f$, if

  1. $f(\overline{x}) < \infty$ and

  2. following holds: [ \lim_{\overset{m(B) \to 0}{\overline{x} \in B}} \mathop{\rlap{-}\int}_B |f(y) - f(\overline{x})| dy = 0 ]

Remark.

  1. Above definition depends on a choice of representation $f$.

  2. Note that $f \in L_{loc}^1 \implies \lim \mathop{\rlap{-}\int}_B f = f(x)$ a.e.

Corollary 1.6.

If $f \in L_{loc}^1(\mathbb{R}^d)$, then almost every point is a Lebesgue point of $f$.

Proof. We apply Theorem 1.4 to $|f(x) - r| \in L^1{loc}(\mathbb{R}^d)$: Since $|f(x) - r| \in L^1{loc}$ for each $r \in \mathbb{Q}$, we have [ \lim_{\overset{m(B) \to 0}{x \in B}} \mathop{\rlap{-}\int}B |f(y) - r| dy = |f(x) - r| \quad \text{for a.e. } x. ] Now let denote $E_r$ which contains all points $x$ such that the above limit does not hold. That is, [ m(E_r) = 0 \quad \text{ and } \quad \lim{\overset{m(B) \to 0}{x \in B}} \mathop{\rlap{-}\int}B |f(y) - r| dy = |f(x) - r| \quad \forall x \notin E_r. ] Let [ E = \bigcup{r \in \mathbb{Q}} E_r ] then $m(E) = 0$. Therefore, our goal is: [ \text{WTS : If } x \notin E, \text{ then } x \text{ is a Lebesgue point. \textit{i.e. }} \lim_{\overset{m(B) \to 0}{x \in B}} \mathop{\rlap{-}\int}B |f(y) - f(x)| dy = 0. ] Suppose that $\overline{x} \notin E$ and $f(\overline{x})$ is finite.Note: This additional assumption can be justified that if $f$ is locally integrable, then $f$ is finite a.e., which have proved in Proposition 1.6 in Chapter 2. Given $\epsilon > 0$, since $\mathbb{Q}$ is dense in $\mathbb{R}$, [ \exists \; r \in \mathbb{Q} \; \; \text{ such that } \; |f(\overline{x}) - r| < \epsilon ] Thus, \begin{align*} \limsup \mathop{\rlap{-}\int}_B |f(y) - f(\overline{x})| dy &\le \limsup \mathop{\rlap{-}\int}_B |f(y) - r| dy + |f(\overline{x}) - r| \ &= 2|f(\overline{x}) - r| < 2\epsilon. \end{align*} Since $0 \le \liminf \mathop{\rlap{-}\int}_B |f(y) - f(\overline{x})| dy$, and $\epsilon$ was arbitrary, we conclude that [ \lim{\overset{m(B) \to 0}{\overline{x} \in B}} \mathop{\rlap{-}\int}_B |f(y) - f(\overline{x})| dy = 0. ]

Remark.

One can use cubes instead of balls, but **rectangles do not work**. (Problem 8)

Definition. A collection ${U_\alpha}$ shrinks regularly to $\overline{x}$ if there exists $c > 0$ such that for each $U_\alpha$, we can find a ball $B$ with [ \overline{x} \in B, \quad U_\alpha \subset B, \quad \text{ and } \quad m(U_\alpha) \ge c m(B). ]

Corollary 1.7.

Let $f \in L_{loc}^1(\mathbb{R}^d)$. If ${U_\alpha}$ shrinks regularly to $\overline{x}$, then [ \lim_{\substack{m(U_\alpha) \to 0 \ \overline{x} \in U_\alpha}} \mathop{\rlap{-}\int}{U\alpha} f = f(\overline{x}) ] for every Lebesgue point of $f$.

Proof. Let $\overline{x}$ be a Lebesgue point of $f$. Since ${U_\alpha}$ shrinks regularly to $\overline{x}$, the following holds for each $\alpha$: [ 0 \le \frac{1}{m(U_\alpha)} \le \frac{1}{c m(B)} \quad \text{and} \quad 0 \le \int_{U_\alpha} |f(y) - f(\overline{x})| dy \le \int_B |f(y) - f(\overline{x})| dy. ] Since both inequalities are positive, we can multiply them to conclude that [ \frac{1}{m(U_\alpha)} \int_{U_\alpha} |f(y) - f(\overline{x})| dy \le \frac{1}{c m(B)} \int_B |f(y) - f(\overline{x})| dy. \tag{$\ast$} ] Recall that $\overline{x}$ is a Lebesgue point of $f$, thus the right hand side of $(\ast)$ goes to 0 as $m(B) \to 0$. Hence, we can finish the proof as follows: [ \lim_{\substack{m(U_\alpha) \to 0 \ \overline{x} \in U_\alpha}} \mathop{\rlap{-}\int}{U\alpha} |f(y) - f(\overline{x})| dy = 0. ]
