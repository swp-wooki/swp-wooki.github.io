Real Analysis 17: Compact Operators

Created on June 26, 2026

2026   ·   real-analysis   measure-theory   lecture-notes   ·   real-analysis

이 글은 2026년 봄학기 실변수함수론(MAT4033) 강의노트를 주제별로 정리한 글입니다.

Definition. A set \(X \subset H\) is compact if every sequence \(\{f_n\}\) in \(X\), there exists a subsequence \(\{f_{n_k}\}\) that converges in \(X\).

Remark.

  1. The closed ball \(B = \{f \in H : \vert \vert f\vert \vert \le r\} \subset H\) is compact if and only if \(\dim H < \infty\).

  2. In an infinite dimensional space, the orthonormal set \(\{e_n\}\) has no converging subsequence because \(\vert \vert e_n - e_m\vert \vert = \sqrt{2}\) for all \(n \neq m\).

Definition. A linear operator \(T : H \to H\) is compact if the closure of \(T(B) = \{T(f) : f \in B\}\) is compact.

Remark.

Equivalently, \(T\) is compact if every bounded sequence \(\{f_n\}\) in \(H\) has a subsequence \(\{f_{n_k}\}\) such that \(\{Tf_{n_k}\}\) converges.

Proposition 6.1.

Let \(T\) be a bounded linear operator on \(H\).

  1. If \(S\) is compact on \(H\), then so are \(ST\) and \(TS\).

  2. If \(\{T_n\}\) is a sequence of compact operators with \(\vert \vert T_n - T\vert \vert \to 0\) as \(n \to \infty\),

  3. If \(T\) is compact, then there exists a sequence of operators of finite rank such that \(\lim_{n \to \infty} \vert \vert T_n - T\vert \vert = 0.\)

  4. \(T\) is compact if and only if \(T^*\) is compact.

Proof.

  1. Obvious.

  2. Let \(\{f_k\}\) be a bounded sequence in \(H\). Since \(T_1\) is compact, there exists a subsequence \(\{f_{1,k}\}\) of \(\{f_k\}\) such that \(\{T_1(f_{1,k})\}\) converges. We can find a further subsequence \(\{f_{2,k}\}\) such that \(\{T_2(f_{2,k})\}\) converges. Repeat this process. Let \(g_k = f_{k,k}\). Then, we find

    \[\begin{aligned} \vert \vert T(g_k) - T(g_l)\vert \vert &\le \vert \vert T(g_k) - T_m(g_k)\vert \vert + \vert \vert T_m(g_k) - T_m(g_l)\vert \vert + \vert \vert T_m(g_l) - T(g_l)\vert \vert \\ &= I_1 + I_2 + I_3 \end{aligned}\]

    Since \(T_m \to T\) and \(\{g_k\}\) is bounded, we find \(m\) large such that \(I_1, I_3 < \frac{\epsilon}{3}\). With this fixed \(m\), we have \(I_2 < \frac{\epsilon}{3}\) for sufficiently large \(k, l\). This implies \(\{T(g_k)\}\) is Cauchy in \(H\), and hence converges.

  3. Let \(\{e_k\}\) be a basis of \(H\). Let \(I = P_n + Q_n\), where \(P_n\) and \(Q_n\) are orthogonal projections onto \(\text{span}\{e_1, \dots, e_n\}\) and \(\text{span}\{e_{n+1}, \dots\}\) respectively. We claim that \(\vert \vert Q_n T\vert \vert \to 0 \quad \text{as } n \to \infty.\) If not, then there exists \(c > 0\) such that \(\vert \vert Q_n T\vert \vert \ge c \quad \text{ for all } n \in \mathbb{N},\) since \(\vert \vert Q_n g\vert \vert \searrow 0\) as \(n \to \infty\) for all \(g \in H\).

    Hence, for each \(n\), there exists \(f_n\) with \(\vert \vert f_n\vert \vert = 1\) such that \(\vert \vert Q_n T f_n\vert \vert \ge c\). Since \(T\) is compact, there exists a subsequence such that \(Tf_{n_k} \to g \quad \text{for some } g.\) But, since \(Q_{n_k}(g) = Q_{n_k} Tf_{n_k} - Q_{n_k}(Tf_{n_k} - g),\) we obtain

    \[\vert \vert Q_{n_k}(g)\vert \vert > \frac{c}{2} \quad \text{for large } k.\]

    which is a contradiction.

  4. If \(T\) is compact, then \(\vert \vert T^* P_n - T^*\vert \vert = \vert \vert P_n T - T\vert \vert \to 0.\) Since \(T^* P_n\) is of finite rank, \(T^*\) is compact by (ii).

Example (Hilbert-Schmidt process).

Let \(H = L^2(\mathbb{R}^d)\) and define \(T : H \to H\) by

\[T(f)(x) = \int_{\mathbb{R}^d} K(x,y) f(y) dy\]

for some kernel \(K\). If \(K \in L^2(\mathbb{R}^d \times \mathbb{R}^d)\), \(T\) is called a Hilbert-Schmidt operator.

Note that \(\vert \vert T\vert \vert \le \vert \vert K\vert \vert _{L^2(\mathbb{R}^d \times \mathbb{R}^d)}\), since

\[\vert T(f)(x)\vert \le \int_{\mathbb{R}^d} \vert K(x,y)\vert \vert f(y)\vert dy \le \left(\int_{\mathbb{R}^d} \vert K(x,y)\vert ^2 dy\right)^{1/2} \vert \vert f\vert \vert _{L^2},\]

we obtain

\[\vert \vert Tf\vert \vert ^2 \le \int \left(\int \vert K(x,y)\vert ^2 dy\right) \vert \vert f\vert \vert ^2 dx = \vert \vert K\vert \vert _{L^2}^2 \vert \vert f\vert \vert ^2.\]

Now, consider an orthonormal basis \(\{\varphi_k\}\) for \(L^2(\mathbb{R}^d)\). Then \(\{\varphi_k(x) \varphi_l(y)\}_{k,l \ge 1}\) is an orthonormal basis for \(L^2(\mathbb{R}^d \times \mathbb{R}^d)\). Thus,

\[K(x,y) \sim \sum_{k,l} a_{kl} \varphi_k(x) \varphi_l(y) \quad \text{with } \sum_{k,l} \vert a_{kl}\vert ^2 < \infty.\]

We define

\[T_n(f)(x) \coloneq \int_{\mathbb{R}^d} K_n(x,y) f(y) dy\]

where \(K_n(x,y) \coloneq \sum_{k,l}^n a_{k,l} \varphi_k(x) \varphi_l(y).\) Then each \(T_n\) is compact. Moreover, since

\[\vert \vert K - K_n\vert \vert _{L^2(\mathbb{R}^d \times \mathbb{R}^d)}^2 = \sum_{\overset{k \ge n}{\text{or} \; l \ge n}} \vert a_{k,l}\vert ^2 \to 0,\]

we have \(\vert \vert T - T_n\vert \vert \le \vert \vert K - K_n\vert \vert \to 0.\) Thus, \(T\) is compact by Proposition 6.1.

Theorem 6.2 (Spectral theorem).

Let \(T\) be a compact symmetric operator on \(H\). Then there exists an orthonormal basis \(\{\varphi_k\}\) of \(H\) that consists of eigenvectors of \(T\). That is,

\[T\varphi_k = \lambda_k \varphi_k\]

for some eigenvalue \(\lambda_k \in \mathbb{C}\).

Moreover, \(\lambda_k \in \mathbb{R}\) and \(\lambda_k \to 0\) as \(k \to \infty\). Conversely, every operator of this form is compact and symmetric.

Note that \(\{\lambda_k\}\) is called the spectrum of \(T\).

Lemma 6.3.

Let \(T\) be a bounded symmetric operator on \(H\).

  1. Every eigenvalue of \(T\) is real.

  2. If \(Tf_i = \lambda_i f_i\), \(i=1,2\) and \(\lambda_1 \neq \lambda_2\), then \(f_1 \perp f_2\).

Proof.

  1. Let \(f\) be an eigenvector corresponding to \(\lambda\), then

    \[\begin{aligned} \lambda(f, f) &= (\lambda f, f) \\ &= (Tf, f) \\ &= (f, T^*f) \\ &= (f, Tf) = (f, \lambda f) = \overline{\lambda}(f, f). \end{aligned}\]

    This implies that \(\lambda = \overline{\lambda} \implies \lambda \in \mathbb{R}\).

  2. Note that

    \[\begin{aligned} \lambda_1(f_1, f_2) &= (\lambda_1 f_1, f_2) \\ &= (Tf_1, f_2) \\ &= (f_1, T^*f_2) \\ &= (f_1, Tf_2) \\ &= (f_1, \lambda_2 f_2) = \lambda_2(f_1, f_2). \end{aligned}\]

    Since \(\lambda_1 \neq \lambda_2\), we have \((f_1, f_2) = 0\).

Lemma 6.4.

Let \(T\) be a compact symmetric operator on \(H\).

  1. If \(\lambda \neq 0\), the dimension of the null space of \(T - \lambda I\) is finite.

  2. There exists at most countable eigenvalues \(\{\lambda_k\}\) such that \(\lambda_k \to 0\) as \(k \to \infty\). Note: Equivalently, for all \(\mu > 0\), there exists \(N\) such that \(\vert \lambda_k\vert < \mu\) for all \(k \ge N\)

Proof.

  1. Let \(V_\lambda = \ker(T - \lambda I)\). If \(\dim V_\lambda = \infty\), then there exists a sequence \(\{\varphi_n\}\) of orthonormal vectors in \(V_\lambda\).

    Since \(T\) is compact, there exists a subsequence \(\{\varphi_{n_k}\}\) such that \(T\varphi_{n_k}\) converges. This implies \(\lambda \varphi_{n_k}\) converges, which contradicts to \(\vert \vert \varphi_{n_k} - \varphi_{n_l}\vert \vert = \sqrt{2} \quad \text{for all } k \neq l.\)

  2. Suppose to the contrary that for each \(\mu > 0\), there exists a sequence \(\{\lambda_n\}\) of distinct eigenvalues such that \(\vert \lambda_n\vert > \mu\).

    Let \(\varphi_n\) be corresponding eigenvector. By Lemma 6.3, \(\{\varphi_n\}\) is orthogonal. We may assume that \(\{\varphi_n\}\) is orthonormal. Since \(T\) is compact, there exists \(\{\varphi_{n_k}\}\) such that \(\{T\varphi_{n_k}\} = \{\lambda_{n_k}\varphi_{n_k}\} \text{ converges}.\) Then

    \[\vert \vert \lambda_{n_k}\varphi_{n_k} - \lambda_{n_l}\varphi_{n_l}\vert \vert ^2 = \lambda_{n_k}^2 + \lambda_{n_l}^2 > 2\mu^2 > 0,\]

    a contradiction.

Lemma 6.5.

Suppose \(T \neq 0\) is compact and symmetric. Then either \(\vert \vert T\vert \vert\) or \(-\vert \vert T\vert \vert\) is an eigenvalue of \(T\).

Proof. Recall that \(\vert \vert T\vert \vert = \sup \{\vert (Tf, f)\vert : \vert \vert f\vert \vert = 1\}.\)

Since \(T\) is symmetric, we have either

\[\vert \vert T\vert \vert = \sup \{(Tf, f) : \vert \vert f\vert \vert = 1\} \text{ or } -\vert \vert T\vert \vert = \inf \{(Tf, f) : \vert \vert f\vert \vert = 1\}\]

Assume the first case, and \(\lambda = \vert \vert T\vert \vert\). Then there exists \(\{f_n\} \subset H\) such that \(\vert \vert f_n\vert \vert = 1\) and \((Tf_n, f_n) \to \lambda\). Since \(T\) is compact, there exists \(\{f_{n_k}\}\) such that \(Tf_{n_k} \to g \in H\) as \(k \to \infty\). Then

\[\begin{aligned} \vert \vert Tf_{n_k} - \lambda f_{n_k}\vert \vert ^2 &= \vert \vert Tf_{n_k}\vert \vert ^2 - 2\lambda(Tf_{n_k}, f_{n_k}) + \lambda^2 \vert \vert f_{n_k}\vert \vert ^2 \\ &\le \lambda^2 - 2\lambda(Tf_{n_k}, f_{n_k}) + \lambda^2 \to 0 \quad \text{as } k \to \infty. \end{aligned}\]

Thus, \(\lambda f_{n_k} \to g\). Since \(T\) is continuous, we have

\[T(\lambda f_{n_k}) = \lambda T(f_{n_k}) \longrightarrow Tg = \lambda g.\]

If \(g = 0\), we get \(\lambda = \lim_{k \to \infty} (Tf_{n_k}, f_{n_k}) = 0\) which implies that \(\vert \vert T\vert \vert = 0 \implies T = 0\), a contradiction to \(T \neq 0\).

Therefore, \(\lambda\) is an eigenvalue of \(T\).

Proof of Theorem 6.2.

Let \(S = \overline{\text{span} \{ \text{eigenvectors of } T \}}\). Then \(S \neq \{0\}\), by Lemma 6.5.

If \(S = H\), then we are done.

Otherwise, \(H = S \oplus S^\perp\) with \(S^\perp \neq \{0\}\). Note that \(f \in S \implies Tf \in S\) and \(g \in S^\perp \implies Tg \in S^\perp\) since \((Tg, h) = (g, Th) = 0\) for all \(h \in S\).

Now consider the projection \(T_1 : S^\perp \to S^\perp\). It is straightforward to check that \(T_1\) is compact and symmetric.

Since \(T_1 \neq 0\), it follows from Lemma 6.5 that \(T_1\) has a nonzero eigenvector in \(S^\perp\). This is also an eigenvector of \(T\).
